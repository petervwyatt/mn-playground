== Testing captions

In Tagged PDF, captions need a block level element internally.

// URL is missing in bookmarks and ToC. See https://github.com/metanorma/metanorma-pdfa/issues/96 
.Caption of an example with a URL to https://pdfa.org
[example%collapsible]
====
An example block used to test captions.
====

.Caption of a figure with a footnote footnote:[Footnote from a caption]
[figure]
====
image::foxit_logo.png[alt=some A1 alt text] 
====
